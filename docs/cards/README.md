# NFC Cards

This directory contains the assets and documentation related to the physical NFC cards used by ReviewTap.

## Card Identification

Each physical card has a unique and permanent ID.

The current naming convention is:

`NFC-XXXX`

Examples:

- NFC-0001
- NFC-0002
- NFC-0003

Card IDs should never be reused simultaneously between different businesses.

## Card Labels

The `labels/` directory contains the templates and printable assets used to identify the physical cards.

Each card should have its Card ID clearly visible on the physical card.

## Card Assignment

Card assignments are tracked in:

`market-research/prospects.md`

The Card Assignments table records:

- Card ID
- Business
- Location
- Status
- Assigned date
- Return date
